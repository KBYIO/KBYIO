I build intelligent software across **e-commerce, health, legal, real estate, and fintech**—working at the intersection of **AI, backend systems, automation, search, structured data, APIs, and cloud infrastructure**.

- Event-driven automation and real-time data pipelines
- Scalable cloud infrastructure
